# One Aim — مدرّب تصويب باللمس للآيفون

مشروع iOS مستقل مصمم لـ **iPhone 12 Pro** ويعمل على **iOS 18.7.8**. الواجهة أفقية، والكروس هير ثابت في مركز الشاشة؛ اسحب بإبهامك لتحريك المنظور واضغط زر الإطلاق بالإبهام الآخر.

> هذا التطبيق مدرّب مستقل فقط. لا يفتح OneState، ولا يقرأ بياناتها، ولا يغيّر ملفاتها، ولا يستطيع الظهور فوقها.

## المزايا

- ثلاثة تدريبات: فلك سريع، هدف متحرك، وفوضى بثلاثة أهداف.
- حساسية لمس قابلة للتعديل من `0.50×` إلى `2.00×`.
- تحكم بحجم الهدف وسرعته ومدة الجولة.
- زر إطلاق يسار أو يمين.
- أربعة ألوان للكروس هير واهتزاز اختياري عند الإصابة.
- إحصاءات فورية: النقاط، الدقة، السلسلة، والوقت.
- واجهة عربية بلا إعلانات أو اتصال إنترنت أو مكتبات خارجية.

## الإعداد المقترح كبداية

على iPhone 12 Pro:

- الحساسية: `1.00×`
- حجم الهدف: `46`
- سرعة الهدف: `130`
- الجولة: `60 ثانية`
- زر الإطلاق: `يسار` حتى يبقى الإبهام الأيمن مخصصًا للسحب والتصويب

حساسية التطبيق مقياس تدريبي داخلي وليست رقمًا مطابقًا لإعداد OneState. عدّلها حتى تصبح مسافة السحب المريحة قريبة من إحساسك داخل اللعبة.

## تشغيله على الآيفون

يلزم Mac عليه Xcode 16 أو أحدث:

1. فك الضغط وافتح `OneStateAimTrainer.xcodeproj`.
2. اختر Target باسم **OneStateAimTrainer** ثم **Signing & Capabilities**.
3. اختر حسابك في خانة **Team**، وغيّر Bundle Identifier إذا طلب Xcode ذلك.
4. وصّل الآيفون، افتحه، وافق على الوثوق بالكمبيوتر، ثم اختره كجهاز التشغيل.
5. اضغط Run أو `⌘R`.

إذا طلب الآيفون تفعيل وضع المطور: الإعدادات ← الخصوصية والأمان ← وضع المطور.

## تصدير IPA موقّع

1. في Xcode اختر جهازًا حقيقيًا أو **Any iOS Device**.
2. اختر **Product → Archive**.
3. من Organizer اختر **Distribute App**.
4. اختر Development أو Ad Hoc حسب حسابك، ثم **Export**.

لا يمكن تضمين IPA موقّع مسبقًا داخل المشروع؛ توقيع Apple مرتبط بحساب المطور والجهاز أو ملف التوزيع الخاص بك.

## بناء IPA غير موقّع عبر GitHub

المشروع يحتوي على workflow باسم **Build unsigned IPA**. عند فتح Pull Request إلى فرع `main` سيعمل البناء تلقائيًا على macOS، ثم يظهر ملف **OneAim-unsigned-IPA** في قسم Artifacts. بعد تنزيله وفك ملف artifact ستجد `OneAim-unsigned.ipa` جاهزًا للتوقيع بأداة التوقيع الموجودة على جوالك.

## روتين تدريب 10 دقائق

1. دقيقتان فلك سريع بحجم هدف `56`.
2. ثلاث دقائق هدف متحرك بسرعة `110`.
3. ثلاث دقائق فوضى بسرعة `140`.
4. دقيقتان فلك سريع بحجم هدف `38`، مع التركيز على الدقة لا السرعة.

إذا نزلت الدقة عن 55% خفّض الحساسية `0.05×`. إذا تجاوزت 80% بسهولة ارفع السرعة أو صغّر الهدف بدل رفع الحساسية مباشرة.

## التحقق

على Mac يمكنك تشغيل الاختبارات من Xcode بالاختصار `⌘U`. يوجد أيضًا فاحص بنية محلي:

```bash
./Scripts/validate_project.sh
```
